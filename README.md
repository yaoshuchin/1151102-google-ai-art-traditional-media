## 📖 專案簡介與特色

本專案將【Google AI 輔助藝術創作與銜接傳統媒材】完整簡報與南投國中美術班 AI 生圖實務指南全面解構並擴充為深度**學員實作手冊**、**影音教學實務**、**視覺指南海報**與 **Prompt 詠唱寶典**。

### 🌟 核心特點：
1. **密碼驗證存取機制**：系統內建安全驗證，輸入研習專屬通行碼即可解鎖，支援密碼記憶與右上角隨時重新上鎖。
2. **多媒體影音教學專區**：內建 6 分 40 秒「創作者的旅程：AI 如何輔助藝術繪圖」實務影片（自適應高清串流、章節快速跳轉、支援下載）。
3. **兩大實務視覺海報圖譜**：
   - 海報 1：AI 藝術創作與生成實務指南（靈感探索、提示詞構建、9:16 / 1:1 / 16:9 規格與參考圖流程）
   - 海報 2：AI 視覺創作與藝術應用指南（線上名畫賞析、Google 藝術典藏延伸、3D 博物館導覽）
4. **南投國中美術班四大主題實務指南教材庫 (共 84 頁投影片)**：
   - 🎨 指南一：AI 藝術創作全攻略（玩轉工具，激發無限創意！）
   - 🔮 指南二：AI 藝術創作魔法書（輕鬆搞懂 AI 生圖技巧）
   - 🏛️ 指南三：AI 藝術創作實務指南（名畫探索到一鍵生圖）
   - ✨ 指南四：AI 藝術生圖魔法課（激發創意的 AI 實務指南）
5. **人物大頭照更換與客製化功能**：
   - 支援即時更換導覽列與講師個人頭像，可點選系統預設（茶米老師原版、Q版動漫造型、色鉛筆手繪造型）或自由上傳個人照片/作品。
6. **學員實作手冊深度擴充 (33 個核心主題)**：
   - 🎯 學習與實作目標
   - 📝 逐步操作流程指引
   - 🎨 傳統媒材銜接與藝術理論重點（油畫厚塗、水彩暈染、色鉛筆筆觸、羊毛氈纖維、黏土微縮、版畫等）
   - 💡 實作技巧與避坑要點
7. **Prompt 詠唱指南（Prompt Guide）**：
   - 包含完整的公式拆解（角色 + 任務 + 限制 + 格式）
   - 完整繁體中文提示詞，附帶 **「一鍵複製」** 按鈕與 Toast 即時回饋
8. **Vibe Coding 成果互動試玩**：
   - 於 Slide 33 內建基於 HTML5 Canvas 的「🍬 糖果敲磚大冒險」小遊戲，支援滑鼠與鍵盤操控、粒子破裂特效與 Web Audio 音效！

## 🛠️ 本地執行方式

無需安裝複雜後端環境，直接使用任何靜態網頁伺服器即可開啟：

```bash
# 使用 Python 內建 HTTP 伺服器
python -m http.server 8000

# 或使用 Node.js http-server / serve
npx serve .
```

開啟瀏覽器前往：`http://localhost:8000`，輸入專屬通行碼即可開始瀏覽學習！
