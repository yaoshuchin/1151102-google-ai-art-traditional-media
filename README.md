## 📖 專案簡介與特色

本專案將【Google AI 輔助藝術創作與銜接傳統媒材】完整簡報（35 頁投影片，排除過渡頁 Slide 3 與結尾頁 Slide 35）全面解構並擴充為深度**學員實作手冊**與 **Prompt 詠唱指南**。

### 🌟 核心特點：
1. **密碼驗證存取機制**：系統內建安全驗證，輸入研習專屬通行碼即可解鎖，支援密碼記憶與右上角隨時重新上鎖。
2. **清晰標示每張簡報外部連結**：所有提及的外部資源（Google Drive、Padlet、Google Docs、Gemini 對話分享、Notion、Panoee、Pics 等）皆以醒目卡片呈現，並提供一鍵複製網址功能。
3. **學員實作手冊深度擴充**：
   - 🎯 學習與實作目標
   - 📝 逐步操作流程指引
   - 🎨 傳統媒材銜接與藝術理論重點（油畫厚塗、水彩暈染、色鉛筆筆觸、羊毛氈纖維、黏土微縮、版畫等）
   - 💡 實作技巧與避坑要點
4. **Prompt 詠唱指南（Prompt Guide）**：
   - 包含完整的公式拆解（角色 + 任務 + 限制 + 格式）
   - 完整繁體中文提示詞，附帶 **「一鍵複製」** 按鈕與 Toast 即時回饋
   - 提供客製化調校建議與關鍵字替換示範
5. **Vibe Coding 成果互動試玩**：
   - 於 Slide 33 內建基於 HTML5 Canvas 的「🍬 糖果敲磚大冒險」小遊戲，支援滑鼠與鍵盤操控、粒子破裂特效與 Web Audio 音效！
6. **全方位檢索與自適應介面**：支援即時關鍵字搜尋、分單元模組篩選、投影片快速跳轉以及深色/淺色主題無縫切換。

## 🛠️ 本地執行方式

無需安裝複雜後端環境，直接使用任何靜態網頁伺服器即可開啟：

```bash
# 使用 Python 內建 HTTP 伺服器
python -m http.server 8000

# 或使用 Node.js http-server / serve
npx serve .
```

開啟瀏覽器前往：`http://localhost:8000`，輸入專屬通行碼即可開始瀏覽學習！
